2D対戦格闘ゲーム
Unityを使用して制作した、2D対戦格闘ゲームです。
 キャラクターごとの通常攻撃・必殺技・SP技に加え、コンボ、ガード、掴み、ステップ、ダッシュなど、対戦格闘ゲームの基本的なシステムを実装しています。
チーム制作では主にプログラムを担当し、プレイヤー操作やバトルシステムの実装だけでなく、仕様調整、他メンバーのコード統合、問題解決などにも取り組みました。

制作で意識したこと
データと処理の分離
技性能やキャラクター性能をScriptableObject側へ分離し、プログラムを直接編集しなくても調整できるようにしました。
これにより、キャラクターや技を追加する際の修正箇所を減らしています。
再利用しやすい設計
Player1・Player2専用の処理を大量に作るのではなく、同じコンポーネントを使用し、設定するデータや入力元によって挙動を変更できる構成を意識しました。
チーム制作での連携
プログラム実装だけでなく、プランナーと仕様について話し合いながら、実装可能な形への調整やパラメータの相談にも参加しました。
また、他メンバーが実装したコードの統合や、不具合が発生した際の原因調査・修正も担当しました。
後輩メンバーにUnityの使い方や実装方法を説明するなど、チーム全体の開発を進めるためのサポートも行いました。
